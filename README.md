## 🚀 Quick Start (Local Development)

### 1. Requirements
- Python 3.10 or 3.11
- Microsoft Edge or Google Chrome (for headless PDF generation)

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Run Web Application
```bash
python app.py
```
Open your browser at `http://127.0.0.1:8088`.

### 4. Run Native Desktop App
```bash
python desktop_main.py
```
Or run `START_VASTUSAUKHYAM_ASTROLOGY.bat`.

---

## 📦 Build Windows Standalone EXE
To compile the standalone Windows executable:
```bash
python -m PyInstaller --noconfirm VastusaukhyamAstro.spec
```
The compiled application will be generated in `dist/Vastusaukhyam_Desktop_New_Build/`.
